Leonida 55 — the offline GTA VI trophy guide and tracker: all 55 official PlayStation 5 trophies with their names, descriptions and grades, a cited guide for each in our own words, a roadmap to the platinum in seven stages, a missable watch, and a checklist that saves in the browser with export and import. No network needed; no Rockstar artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the entry dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
